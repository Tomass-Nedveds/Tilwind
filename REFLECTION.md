# Individuālā refleksija

> **Šis fails apzināti nav aizpildīts.** Uzdevuma nosacījumi nosaka, ka refleksija jāizpilda patstāvīgi, neizmantojot mākslīgā intelekta rīkus — tāpēc atbildes uz šiem jautājumiem jāuzraksta tev pašam/pašai.

1. Kas bija visgrūtākais šajā CSS → Tailwind migrācijas uzdevumā?

Visgrūtāk bija pārveidot CSS stilus uz Tailwind klasēm.

2. Kuras Tailwind utilītklases vai koncepti sākumā bija neskaidri, un kā tu tos izpratī?

Sākumā nesapratu dažas flex, grid, gap un izmēru klases. Izmēģinot tās, sapratu, kā tās darbojas.

3. Kā mainījās tava izpratne par oriģinālo `styles.css`, to pārveidojot uz Tailwind?

Es labāk sapratu, kā darbojas oriģinālais CSS un lapas izkārtojums. 

4. Kuru daļu no darba tu vari paskaidrot pilnībā patstāvīgi, bez atsaukšanās uz dokumentāciju vai piezīmēm?

Varu iei.

5. Ko tu darītu citādi, ja šo migrāciju sāktu no jauna?

Vairāk atrastu informācija internetā un paskatitos vairāku viedo par Tailwind

6. Kā mākslīgā intelekta rīku izmantošana (ja tāda bija) ietekmēja tavu mācīšanos — palīdzēja vai traucēja saprast Tailwind CSS?

MI palīdzēja ātrāk saprast neskaidras lietas.
